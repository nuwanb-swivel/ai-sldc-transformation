- (decision) AD-2: Authorization lives exclusively in the DAL (requireSession/requireAdmin), never solely in UI conditionals or Proxy. Binds FR-4,FR-5. Prevents an admin-only check implemented only as UI-hiding, leaving a server-side bypass path.

Binds FR-3,FR-4 UX per EXPERIENCE.md. Prevents divergent optimistic-reconciliation mechanisms between idea-card and idea-detail surfaces.
- (decision) AD-6: Cache Components (, cacheComponents) stay disabled/default for v1 — all reads per-request dynamic + revalidatePath after mutations. Binds all. Prevents inconsistent freshness (one route cached, another not) contradicting PRD's 'reflected on next view' requirement and the optimistic-reconciliation pattern.

- (decision) AD-8: Role (employee|admin) is a single field on the auth library's own user record (schema-extended), never a second allowlist/table. Binds FR-4,FR-5,Glossary(Admin). Prevents two admin-identity sources of truth drifting out of sync.
